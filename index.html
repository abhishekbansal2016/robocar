Teach a camera task

No learned policy

Show what the camera should see, then label the correct movement. Start with a high-contrast line on a clear floor. This trains a tiny image policy, independently of YOLO.

Data collection mode

Start recording, then drive with the remote buttons or arrow/WASD keys. Camera images are automatically labelled with the command active at exposure time. Release to teach Stop. Record at least two separate runs.

Collect at least two separate sets for every action. Reposition the robot between sets; the latest set is held out for validation. No motors move during collection, training or prediction-only testing.

24×18 RGB → 24 hidden units → four actions, plus optional Backward when demonstrated. Learned drive uses up to 100 ms pulses, confidence ≥80%, two consistent predictions and photos ≤1 second old. These limits do not make the model collision-aware. Lost-line examples must be labelled Stop. Add varied backgrounds, lighting and recovery views.
